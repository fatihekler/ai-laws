SOURCE ACQUISITION

Her kaynak için önce `86_NOTEBOOKLM/NOTEBOOKLM_SOURCE_ACQUISITION_MANIFEST.csv` içindeki kaydı fresh doğrula.

Acquisition class:

- URL_DIRECT_PREFERRED
- PDF_DOWNLOAD_ALLOWED
- MANUAL_DOWNLOAD_REQUIRED
- OFFICIAL_SOURCE_NEEDS_VERIFICATION
- PAYWALLED_DO_NOT_VENDOR

PDF_DOWNLOAD_ALLOWED ise:

- resmî hosttan indir;
- exact document ID/version/date doğrula;
- rights/use state doğrula;
- dosya adını `SOURCE_ID__JURISDICTION__DOCUMENT_ID__VERSIONDATE.ext` şeklinde kaydet;
- SHA-256 hesapla;
- byte size/content type kaydet;
- dosyayı aç ve beklenen belge olduğunu doğrula;
- ledger'a işle.

URL_DIRECT_PREFERRED ise:

- resmî URL/currentness doğrula;
- Notebook'a URL olarak eklemeye hazırla;
- retrieval date kaydet;
- Notebook ingest sonrası source identity locator testi yap.

MANUAL_DOWNLOAD_REQUIRED ise guessed deep-link üretme. Resmî portal üzerinden exact document identity pinlenmeden ilerleme.

PAYWALLED_DO_NOT_VENDOR ise geçerli lisans yoksa full text indirme/yükleme yapma; metadata/reference tut.

NOTEBOOK YÜKLEME AŞAMALARI

1. Pack hazırlığı.
2. Yalnız verified/acquisition-ready kaynakları seç.
3. Authority class'ı source title'da görünür tut.
4. Kaynakları yükle veya resmî URL ekle.
5. Notebook/source count ve tarih kaydet.
6. Substantive soru sormadan SOURCE-IDENTITY TEST uygula.
7. Notebook'tan her source için SOURCE_ID/title/document ID/jurisdiction/date/locator iste.
8. GitHub manifest ile karşılaştır.
9. Mismatch => NOTEBOOK_SOURCE_MISMATCH ve o kaynakla analiz STOP.
10. Authority separation test uygula.
11. Sonra research question catalog ile claim-level analiz yap.
12. Notebook bulgularını SUPPORTING_RESEARCH olarak dışa aktar.
13. Her material claim'i primary/official source üzerinden bağımsız recheck et.
14. VERIFIED / PARTIAL / CONFLICT / UNKNOWN sınıfı ver.
15. Gerekirse human legal review gate'e gönder.
16. GitHub evidence/claim record oluştur.
17. Refresh trigger kaydet.
18. Bounded unit sonunda STOP et.

NOTEBOOK OUTPUT HEADER:

CANONICAL = FALSE
PRIMARY_SOURCE_RECHECK_REQUIRED = YES

GLOBAL COVERAGE

"Bütün hukuk" tek batch değildir. Coverage jurisdiction-by-jurisdiction ve domain-by-domain tamamlanır. Bir ülkenin registry'de görünmesi `researched` anlamına gelmez.

CURRENTNESS

Amendment/corrigendum/new consolidated text/effective date/transposition deadline/treaty-status change/new case/regulator interpretation/source replacement/freshness expiry => REFRESH_DUE.

Notebook'ta erişilebilir olması current law olduğu anlamına gelmez.
